# Expression stickers

Seven 320 × 320 transparent PNGs derived from the reference sheet supplied by the project owner in this redesign request. The expressions and glasses come from that sheet, not a Judy Hopps asset or a stock character. Local Pillow processing separates foreground and adds chestnut hair, warm skin, blush, a sage shirt, highlights and a soft paper rim/shadow. No external URLs or generative API are used.

`tools/prepare_expressions.py` reproduces the edits when given the original reference. The original private attachment and its local path are not included. Original illustration authorship was not supplied; these supplied-reference derivatives are not asserted to be original MIT artwork. All task functionality is independent of the images.

Mapping: idle/waiting = puzzled bust; starting = sparkle; searching = wide eyes; downloading = thinking/spinner; validating/cancelled = concentrated/resting; success = pleased; issue = frustrated. State transitions are driven by backend events, never elapsed time. The top-right expression on the original eight-expression sheet (the one the user described as showing two feet) is deliberately excluded at the user's request.
