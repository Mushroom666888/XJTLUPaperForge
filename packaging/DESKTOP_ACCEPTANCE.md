工作台页脚和 `/health` 的版本/源码指纹应与归档内 `release-notes/manifest.json` 的 `build` 一致。报告中记录每一项的操作者、时间、实际操作、结果和源码外证据位置；“待验收”、平台跳过和没有设备均不能填为通过。Windows 检查脚本输出的 JSON 仅证明合成检查；即使 PATH 和注册表都未检出 Python，也必须另附干净镜像/虚拟机的准备证据。
