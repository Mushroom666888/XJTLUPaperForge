# XJTLU PaperForge

A local Windows workbench for XJTLU students to collect past examination papers by course code. Users choose 192 or 300 DPI, authenticate directly with their school in Chrome, and receive only verified PDFs in one folder per course. The school controls access and availability; this independent tool does not promise a fixed paper count.

The primary task is to enter courses, choose quality and a destination, then understand what is happening without reading technical logs. Accounts, browser sessions and downloaded papers stay outside this repository. Never fabricate progress or describe a partial export as success.

The user's redesign preserves the cream and forest palette and two-column workbench, adds a small forest scene and seven expressive stickers cropped and colorized from their supplied sheet. This explicitly replaces the earlier Judy/rabbit request. The user authorized autonomous implementation, verification and a local commit, without a push.

Assumptions: Windows 10/11, installed Chrome, a local Python HTTP server and a browser UI; no desktop web container. Native folder selection must therefore be implemented by the trusted local backend. School login can require the user and network access; synthetic browser tests are never evidence of a live school export.
